Tripeey | Your T-Shirt Store

This project is a revamped version of a final vanilla web development project for CS36 - Web Systems & Technologies, serving as an introduction to core JavaScript and PHP (vanilla). For this static version, there will be no backend php involved.

Features Implemented
  • Dynamic product rendering with the Fetch API.
  • Interactive shopping cart with real-time updates.
  • Modular CSS for a responsive and modern UI.

Disclaimer: This project is for educational purposes only and was created to demonstrate web development techniques such as dynamic content rendering, API integration, and user interface design.
